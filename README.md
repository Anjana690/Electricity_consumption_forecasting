 Electricity_consumption_forecasting

📌 Project Description

This project focuses on predicting future electricity consumption using machine learning techniques based on historical data such as time, temperature, humidity, and day type.

🎯 Objective

The main objective is to accurately forecast electricity usage and support efficient energy management by maintaining a balance between supply and demand.

🛠️ Features

* Data preprocessing (handling missing values, formatting date & time)
* Exploratory Data Analysis (EDA) to identify patterns and trends
* Feature engineering for improved model performance
* Machine learning models (Linear Regression, Decision Tree, Random Forest)
* Model evaluation using MAE, MSE, and RMSE
* Future electricity consumption prediction

 📊 Output

* Predicted electricity consumption values
* Visualization of usage patterns
* Identification of peak usage time (evening hours)
* Best model selection (Random Forest performed best)

📁 Files Included

* Dataset (Excel file)
* Model / Analysis
* Output results (graphs)

✅ Conclusion

The Random Forest model provided the best performance among all models. The analysis shows that electricity consumption is highest during evening hours and lowest during midnight. Time and day type are key factors influencing electricity usage.
